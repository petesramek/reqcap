# ReqCap

ReqCap is a lightweight .NET library for evaluating relationships between **requirements** and **capabilities**.

The goal is to provide a simple and extensible foundation for modeling compatibility between entities without hardcoded rules.

---

## 🧠 Core Idea

An entity can define:

- **Capabilities** — what it provides
- **Requirements** — what it needs

ReqCap evaluates whether a set of capabilities satisfies given requirements.

---

## 🚧 Status

Early stage — design in progress.

---

## 🎯 Goals

- Keep the model simple and flexible
- Avoid hardcoded domain logic
- Stay independent of any specific application (e.g., gardening, IoT)
- Be usable as a general-purpose library
